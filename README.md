# 📅 Modern Calendar App (Next.js + TypeScript)

A beautifully designed and responsive Calendar Web Application built using Next.js (App Router) and TypeScript, featuring interactive date navigation and a clean modern UI.

---

## 🌐 Live Demo

👉 https://moderncalendar.netlify.app/

---

## ✨ Features

* 📆 Dynamic calendar rendering
* 🔄 Month & year navigation
* 📍 Highlight current day
* 🧩 Modular component-based architecture
* ⚡ Built with Next.js App Router
* 🎨 Clean and modern UI
* 📱 Fully responsive design
* 📝 Notes section for future enhancements

---

## 🛠️ Tech Stack

* **Framework:** Next.js (App Router)
* **Language:** TypeScript
* **Styling:** Tailwind CSS / CSS
* **Deployment:** Netlify

---

## 🚀 Getting Started

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/Madhurya3030/Calendar.git
```

### 2️⃣ Navigate to Project Folder

```bash
cd Calendar
```

### 3️⃣ Install Dependencies

```bash
npm install
```

### 4️⃣ Run Development Server

```bash
npm run dev
```

👉 Open in browser:
http://localhost:3000

---

## 🧠 How It Works

* **CalendarGrid.tsx** → Generates the calendar layout
* **DayCell.tsx** → Handles individual date rendering
* **CalendarApp.tsx** → Core logic & state management
* **App Router (app/)** → Handles routing and layout
